ShopNest – Tarea 3


Este proyecto es la primera versión funcional de ShopNest, una pequeña tienda en línea que funciona desde la consola. Fue realizado como parte de la Tarea 3 de la materia Desarrollo de Software.

El programa permite registrar clientes, ver productos, agregar artículos al carrito, aplicar cupones, realizar pagos y recibir un resumen de compra. Todo funciona de manera sencilla y directa.


--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------


Funciones de ShopNest

Registrar o elegir un cliente

Ver el catálogo de productos

Agregar productos al carrito

Quitar productos del carrito

Ver lo que lleva el carrito

Aplicar cupones

Confirmar la compra

Pagar con tarjeta o efectivo

Elegir el tipo de envío

Ver el historial de compras

Revisar la lista de clientes y emprendedores



--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------


Pasos para ejecutar el programa

Para que todo funcione correctamente, sigue estos pasos:

1. Abre la terminal dentro de la carpeta donde está el archivo Main.java

Ejemplo:
C:\Usuarios\TuUsuario\Documentos\ShopNest-Tarea3>

2. Escribe este comando para que se vean bien los acentos y caracteres especiales:

chcp 65001

3. Si deseas actualizar los archivos antes de usar el programa, escribe:

javac Main.java

4. Para iniciar el sistema, escribe:

java Main

Después de eso aparecerá el menú principal y podrás usar todas las opciones desde la consola.
